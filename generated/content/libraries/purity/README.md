# Purity MCP

Wraps the moodboard **purity** tool (`cog-ai-intheshell/moodboard-purity-1`): given a
bundle of persona images, it extracts the aesthetic — palette, tags, emotions — and
scores moodboard coherence ("purity").

Output feeds the per-app **universe** (`apps/<app>/universe/tokens.override.json`) and the
illustration style. This is the engine behind the "Lean Creative Universe."
