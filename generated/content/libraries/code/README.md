# Code library

Reusable Swift / Python snippets we know we'll repeat. Each lives in its own folder
with a 3-line header: what it does, its inputs/outputs, and which app first needed it.

**Rule:** if a sprint writes something twice, it belongs here. Empty-but-defined is
fine in Phase 1 — Sprint 1 seeds the first entries (camera capture + image encryption
under `vision-camera/`).
