# Knowledge / memory modules

Per-vertical corpora the apps and agents draw on. One folder per domain, each with a
README naming the source and how it's used.

Phase 1 seeds only `color-theory/` for Sprint 1:
- `color-theory.md` — properties, harmonies, the 7-step palette process, 60-30-10, accessibility,
  emotion→hue, and cultural cautions (the design system's color reference).
- `seasons.md` — the seasonal-analysis subset used by the Color Matching app.

As verticals grow we merge and reuse rather than re-collecting.
