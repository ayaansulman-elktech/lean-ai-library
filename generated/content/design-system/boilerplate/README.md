# Design project boilerplate

The starter kit every new app's design copies:

- the lean component set (atoms → templates) it will actually use,
- the template screens (onboarding, paywall, core, settings),
- a `tokens.override.json` skeleton for the universe,
- the design checklist (hierarchy, contrast, scannability, flow…).

Spinning up a niche = **copy this → generate the universe** (`tokens.override.json` +
moodboard via the purity tool) → apply. Keeps every app Apple-native and consistent from
screen one.
