# SF Symbols

Catalog + usage rules for Apple **SF Symbols** (the native icon set).

Documents which symbol maps to which action, weight/scale rules, and rendering mode
(monochrome / hierarchical / palette) per token. Prefer SF Symbols over custom icons for
Apple-native feel and built-in accessibility.

No assets to vendor — the symbols ship with the OS; this folder is the **selection +
usage policy**, not image files.
