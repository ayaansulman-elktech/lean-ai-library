# Patterns (Apple-DNA libraries)

Reusable interaction / experience patterns drawn from Apple's design DNA. One subfolder
per library:

| Library | What it holds |
|---|---|
| `animation/` | motion patterns — transitions, springs, scroll-driven effects |
| `continuous-experience/` | cross-device continuity — Handoff, Universal Clipboard, calls-into-app |
| `enhance-experience/` | system integrations that elevate UX — Live Activities, App Intents, widgets, Siri |
| `interaction-ideas/` | a catalog of interaction concepts to pull from per niche |

Each entry documents **what it is, when to use it, and the components/tokens it touches**.
These feed the prototype + universe-enhancing design steps.
